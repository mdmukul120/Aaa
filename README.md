# শব্দ AI — ইন্টারনেট থেকে শেখা ভাষা-মডেল

একটা সম্পূর্ণ, চলমান সিস্টেম: **বিশ্বের বড় সাইটের লেখা → Supabase (১ GB ফ্রি) → বাংলা+ইংরেজি ভাষা-মডেল → পরবর্তী শব্দের অনুমান**, সাথে ওয়েব UI, সার্চ আর "প্রশ্ন করলে গুছিয়ে উত্তর" — সব একই প্রজেক্টে।

> **লাইভ:** https://shobdo-ai.onrender.com · মডেল এখন **নিউরাল (ছোট ট্রান্সফরমার) + n-gram** মিশ্রণ।

---

## ১. কী কী আছে

| অংশ | ফাইল | কাজ |
|---|---|---|
| ওয়েব সার্ভার + API | `server.py` | শুধু Python স্ট্যান্ডার্ড লাইব্রেরি; UI সার্ভ করে, JSON API দেয় |
| নিউরাল ভাষা-মডেল | `neural.py` | ছোট GPT-ধাঁচের ট্রান্সফরমার — সার্ভারে শুধু NumPy দিয়ে চলে (PyTorch/GPU লাগে না) |
| নিউরাল ট্রেইনার | `train_neural.py` | JAX দিয়ে CPU-তেই ট্রেইন/ফাইন-টিউন; GitHub Actions থেকে নিজে নিজে চলে |
| n-gram ভাষা-মডেল | `ngmodel.py` | Interpolated n-gram LM (trigram + bigram + skip-gram + unigram) — সঙ্গে সঙ্গে শেখে |
| ক্রলার / এক্সট্র্যাক্টর | `crawler.py` | উইকি API, RSS/Atom ফিড, যেকোনো URL থেকে মূল লেখা আলাদা করা |
| বাল্ক লার্নার | `crawl_hf.py` | HuggingFace-এর `wikimedia/wikipedia` ডেটাসেট থেকে হাজারো নিবন্ধ |
| CLI ট্রেইনার (n-gram) | `train.py` | `--crawl N`, `--train`, `--ask "…"`, `--sync --upload` |
| ওজন ফাইল | `models/shobdo-neural.npz` | ট্রেইন করা নিউরাল মডেল (ওজন + টোকেনাইজার + মেটা, ~৫ MB) |
| স্বয়ংক্রিয় ট্রেইনিং | `.github/workflows/train-neural.yml` | সাপ্তাহিক ফাইন-টিউন → Supabase Storage → সার্ভার নিজে নামায় |
| ডেটাবেস লেয়ার | `db.py` | Supabase REST (service key সার্ভার-সাইড), লোকাল JSONL ফলব্যাক |
| সাইট রেজিস্ট্রি | `sources.py` | ২৩+ বড় সাইট, ক্যাটাগরি, ভাষা, ফিড লিংক |
| UI | `static/index.html` | এক ফাইল, কোনো CDN নেই — বাংলা ড্যাশবোর্ড |

## ২. আর্কিটেকচার

```
🌐 ইন্টারনেট                                🗄 Supabase (Postgres ১ GB + Storage)
 ┌──────────────────────────┐   insert   ┌────────────────────────────────┐
 │ Wikipedia bn/en (API/HF) │ ─────────► │ documents (url UNIQUE, content)│
 │ BBC বাংলা · প্রথম আলো     │            │ sites · learning_runs · …      │
 │ ২৩+ সাইটের RSS ফিড        │            │ Storage: মডেল ফাইল             │
 └────────────┬─────────────┘            └──────┬──────────────────┬──────┘
              │ সঙ্গে সঙ্গে (সার্ভারে)            │ সাপ্তাহিক          │ FTS
              ▼                                 ▼ (GitHub Actions)  ▼
      ┌────────────────┐               ┌──────────────────┐  ┌──────────────────┐
      │  n-gram LM     │               │ নিউরাল ট্রান্সফরমার │  │ search_documents │
      │ নতুন তথ্য দ্রুত  │               │ ভাষার গঠন বোঝে    │  └──────────────────┘
      └───────┬────────┘               └────────┬─────────┘
              └──────────► মিশ্রণ ◄──────────────┘
                 p = w·নিউরাল + (1−w)·n-gram
                          ▼
   ⚡ পরবর্তী শব্দ · ✍️ লেখা চালিয়ে যাওয়া · 🔎 জিজ্ঞাসা/উত্তর
```

**কেন দুই মডেল:** নিউরাল মডেল অনেক লেখা থেকে ভাষার গঠন শেখে (দূরের কনটেক্সটও দেখে), কিন্তু ট্রেইন করতে
সময় লাগে — তাই সেটা GitHub Actions-এ হয়। n-gram মডেল "শেখাও" চাপলেই সেকেন্ডে নতুন লেখা থেকে শেখে।
দুটো মিশিয়ে দিলে একা যেকোনোটার চেয়ে ভালো ফল হয় (নিচে পরিমাপ)। নিউরাল ফাইল না থাকলে বা
`numpy` ইনস্টল না থাকলে সার্ভার নিজে থেকেই শুধু n-gram দিয়ে চলে।

ডেটা Supabase-এ থাকায় সার্ভার বন্ধ হলেও কিছু হারায় না; শেখা n-gram মডেল কয়েক মিনিট পরপর Supabase Storage-এ
ওঠে, সার্ভার জেগে উঠলে সেখান থেকেই নামায়।

## ৩. ডেটাবেস (Supabase · প্রজেক্ট `Shobdo AI`)

| টেবিল | কী থাকে |
|---|---|
| `documents` | url (unique), title, lang, content, char_count — **স্ক্রল করা সব লেখা** |
| `sites` | domain, name, homepage, category, lang, feed_url — বড় সাইটের লিংক |
| `learning_runs` | কখন কোন উৎস থেকে কত পেজ/টোকেন শেখা হলো |
| `model_stats` | vocab, uni/bi/tri counts |
| `predictions` | ইনপুট, শীর্ষ পরামর্শ, সম্ভাবনা (ফিডব্যাক লগ) |

ফাংশন: `search_documents(q, lim)` — Postgres ফুল-টেক্সট সার্চ + `ts_headline` স্নিপেট; `db_usage()` — সাইজ হিসাব। RLS চালু, ডিফল্টে কোনো পাবলিক পলিসি নেই — শুধু সার্ভার-সাইড **service key** দিয়ে অ্যাক্সেস।

**বর্তমান ব্যবহার:** ডেটাবেস **২৩ MB** / ১,০২৪ MB · `documents` টেবিল **১২ MB** · **১,০৭২** ডকুমেন্ট — অর্থাৎ ফ্রি প্ল্যানের প্রায় ২% খরচে।

## ৪. মডেল

### ৪.১ নিউরাল (`neural.py`, `train_neural.py`)

- **গঠন:** decoder-only ট্রান্সফরমার — ৪ স্তর × ১৬০ প্রস্থ × ৪ attention head, কনটেক্সট ৯৬ টোকেন,
  **২৫.৩ লক্ষ (2.53M) প্যারামিটার** (pre-LayerNorm, GELU, tied embedding)
- **টোকেনাইজার:** SentencePiece (unigram, ৮,০০০ subword) — বাংলা ও ইংরেজি একসাথে; অচেনা শব্দও টুকরো জুড়ে বানাতে পারে
- **ট্রেইনিং:** AdamW + warmup/cosine learning-rate + gradient clipping; সবচেয়ে ভালো validation loss-এর ওজনই রাখা হয়
- **ডেটা:** বাংলা উইকিপিডিয়ার ৩,৮০৯টি নিবন্ধ + ইংরেজি WikiText-2-এর ৭৩১টি নিবন্ধ (৩% যাচাইয়ের জন্য আলাদা রাখা) — ৭৩ লক্ষ subword টোকেন
- **সার্ভারে চালানো:** শুধু NumPy (KV-cache সহ) — প্রতি কি-স্ট্রোকে ১৫–২০ ms-এর মতো; ওজন float16, ফাইল ৪.৮ MB
- **পরের শব্দ:** subword-এর উপর beam search করে পুরো শব্দের সম্ভাবনা বের করা হয়

### ৪.২ n-gram (`ngmodel.py`)

- trigram + bigram + skip-gram + unigram, কনটেক্সট-নির্ভর λ; অজানা শব্দে prefix-fallback
- টোকেনাইজার: Unicode NFC, ZWJ/ZWNJ ও নুকতা স্বাভাবিকীকরণ, ছোট হাতের অক্ষর (The/the একই শব্দ)
- `LOW_MEM=1`-এ মোট এন্ট্রির বাজেট (`MAX_ENTRIES`) ছাড়ালে তবেই বিরল জোড়া ছাঁটা হয় — নতুন শেখা আর মুছে যায় না

### ৪.৩ সৎ পরিমাপ (অদেখা ১৩৬টি নিবন্ধ, মডেল এগুলো ট্রেইনিংয়ে দেখেনি)

| মডেল | top-1 | top-5 |
|---|---|---|
| শুধু n-gram | ১৯.৬% | ৩২.৪% |
| শুধু নিউরাল | ২২.৪% | ৩৬.৭% |
| **মিশ্রণ (যা সার্ভার ব্যবহার করে)** | **২৩.৭%** | **৩৮.৯%** |

২,০১০টি জায়গায় পরের শব্দ আন্দাজ করিয়ে মাপা (top-1 = প্রথম পরামর্শটাই ঠিক; top-5 = প্রথম পাঁচটার মধ্যে ঠিক শব্দ আছে)।
তুলনার n-gram একই ট্রেইনিং লেখা থেকে গড়া পূর্ণ মডেল; সার্ভারের `LOW_MEM` ধাঁচের ছোট n-gram একা পায় ১৭.৭% / ২৮.২%,
নিউরালের সাথে মিশে ২৩.৫% / ৩৮.২%। নিউরাল মডেলের validation perplexity: **৯৭.২** (subword প্রতি)।

সীমাবদ্ধতা: পরীক্ষাটা উইকিপিডিয়া-ধাঁচের লেখায়; খবর বা কথ্য ভাষায় ফল আলাদা (সাধারণত কম) হবে, কারণ নিউরাল মডেল
এখনো শুধু বিশ্বকোষের লেখা দেখেছে। ট্রেইনিং হয়েছে ২-কোর CPU-তে মোট ~৯০ মিনিট — মডেল তখনো উন্নতি করছিল।

> এটা ChatGPT নয় — কয়েক মিলিয়ন প্যারামিটারের ছোট মডেল, ChatGPT-র চেয়ে লক্ষ গুণ ছোট। পরের শব্দ ভালো আন্দাজ করে,
> বাক্যের গঠন মোটামুটি ঠিক রাখে, কিন্তু লম্বা লেখায় অর্থ ধরে রাখতে পারে না এবং তথ্য ভুল বলতে পারে।
> আরও ডেটা + আরও সময় ট্রেইন করলে ভালো হয় (নিচে ৫.১)।

## ৫. চালানোর নিয়ম

```bash
pip install -r requirements.txt
cp .env.example .env          # Supabase URL + service key + ADMIN_TOKEN বসান

python server.py              # http://localhost:8000
python train.py --crawl 300   # ইন্টারনেট থেকে ~৩০০ পেজ এনে শেখাও (n-gram)
python crawl_hf.py --bn 300 --en 200   # বাল্ক: হাজারো উইকি নিবন্ধ
python train.py --ask "বাংলা ভাষা"      # CLI-তে টেস্ট
python train.py --sync --upload        # Supabase-এর সব ডেটা থেকে n-gram নতুন করে গড়ে Storage-এ তোলো
```

### ৫.১ নিউরাল মডেল ট্রেইন করা

```bash
pip install -r requirements-train.txt      # jax (শুধু CPU-তেই চলে)

# Supabase-এর সব ডকুমেন্ট দিয়ে রিপোর মডেল ফাইন-টিউন করে Storage-এ তোলা
python train_neural.py --from-supabase --init models/shobdo-neural.npz \
       --out data/shobdo-neural.npz --minutes 120 --upload

# একদম নতুন, বড় মডেল (ভালো কম্পিউটার/বেশি সময় থাকলে)
python train_neural.py --from-supabase --width 256 --layers 6 --heads 8 --ctx 128 \
       --minutes 600 --out models/shobdo-neural.npz
```

**স্বয়ংক্রিয়:** `.github/workflows/train-neural.yml` প্রতি সপ্তাহে GitHub-এর ফ্রি রানারে এটা চালায়
(অথবা Actions ট্যাব → *Train neural model* → *Run workflow*)। একবার দুটো secret বসাতে হবে —
repo → Settings → Secrets and variables → Actions: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`।
ট্রেইনিং শেষে ফাইল Supabase Storage-এ ওঠে; লাইভ সার্ভার ৩০ মিনিটের মধ্যে নিজেই নামিয়ে বদলে নেয় — নতুন ডিপ্লয় লাগে না।

### ৫.২ সেটিংস (environment variable)

| নাম | ডিফল্ট | কাজ |
|---|---|---|
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` | — | ডেটাবেস + Storage (শুধু সার্ভারে; কখনো ব্রাউজারে/গিটে নয়) |
| `ADMIN_TOKEN` | খালি | সেট থাকলে `/api/learn` ও `/api/autolearn`-এ `x-admin-token` হেডার লাগে। **পাবলিক সার্ভারে অবশ্যই দিন** |
| `LOW_MEM` | `0` | `1` = ৫১২ MB হোস্টের জন্য ছোট n-gram |
| `MAX_ENTRIES` | `400000` (LOW_MEM) | n-gram-এর এন্ট্রি বাজেট |
| `MAX_DOCS` | `40000` | ডেটাবেসে এর বেশি ডকুমেন্ট হলে নতুন শেখা থামে (১ GB ফ্রি সীমা রক্ষা) |
| `NEURAL` | `1` | `0` = নিউরাল বন্ধ, শুধু n-gram |
| `NEURAL_BUDGET_MS` | `350` | নিউরাল প্রেডিকশনের গড় সময় এর বেশি হলে হালকা মোড |
| `AUTOLEARN` | `0` | `1` = চালু হয়েই প্রতি ২ মিনিটে নিজে শেখে |

🔒 = `ADMIN_TOKEN` সেট থাকলে `x-admin-token` হেডার লাগে (UI নিজেই একবার জিজ্ঞেস করে মনে রাখে)।

**নিরাপত্তা:** প্রতি-IP ও সামগ্রিক রেট-লিমিট (৪২৯), অনুরোধের আকার ৬৪ KB পর্যন্ত (৪১৩), `url` শুধু পাবলিক
http/https ঠিকানা — localhost/প্রাইভেট নেটওয়ার্ক/ক্লাউড-মেটাডেটা ঠিকানা প্রত্যাখ্যাত হয়, redirect-এও যাচাই হয় (SSRF রোধ);
সেভ করা n-gram ফাইল সীমিত unpickler দিয়ে পড়া হয়।

## ৭. উৎস ও লাইসেন্স

নিউরাল মডেলের প্রাথমিক ট্রেইনিং: বাংলা উইকিপিডিয়ার নিবন্ধ ও ইংরেজি WikiText-2 (দুটোই Wikipedia-র লেখা, CC BY-SA)।
Wikipedia (bn/en) — CC BY-SA; BBC/Al Jazeera/Guardian/প্রথম আলো ইত্যাদি রাষ্ট্রীয় RSS ফিড; `wikimedia/wikipedia` ডেটাসেট (HuggingFace)। শুধু পাবলিক লেখা, কোনো ব্যক্তিগত ডেটা নয়।

## ৮. হোস্টিং

সব ধাপের বিস্তারিত: **[`deploy/DEPLOY.md`](deploy/DEPLOY.md)**

| হোস্ট | খরচ | উপযুক্ততা |
|---|---|---|
| **Hugging Face Spaces** (Docker) | ⚠️ এখন PRO লাগে | শুধু Static ফ্রি — Python চলবে না |

| **VPS + docker compose** | ~$৪–৬/মাস | ✅ সস্তা দীর্ঘমেয়াদে |

ফাইল প্রস্তুত: `Dockerfile`, `fly.toml`, `render.yaml`, `Procfile`, `docker-compose.yml`, `.dockerignore`।

**গুরুত্বপূর্ণ:** ফ্রি হোস্টের ডিস্ক অস্থায়ী — তাই সার্ভার চালু হওয়ার সময় `_bootstrap()` Supabase Storage থেকে n-gram মডেল নামায়
(না থাকলে বা পুরোনো টোকেনাইজারের হলে সব ডকুমেন্ট এনে নিজেই নতুন করে গড়ে ও Storage-এ তুলে রাখে)। নিউরাল ওজন রিপোতেই
থাকে (`models/`), আর Storage-এ নতুনতর থাকলে সেটাই নেয়।
service key কখনো ব্রাউজারে বা গিটে যাবে না — `.env` শুধু সার্ভারের জন্য, হোস্টে env var/secret হিসেবে বসান।

## ৯. পরবর্তী উন্নতির পথ

1. **আরও ডেটা + লম্বা ট্রেইনিং** — নিউরাল মডেলের মান প্রায় পুরোটাই এর উপর নির্ভর করে (১০k–৫০k নিবন্ধ, কয়েক ঘণ্টা)

3. শব্দের মাঝখানে থাকা অবস্থায় শব্দ-সমাপ্তি (autocomplete) — subword মডেলে সহজ
4. Supabase `pgvector` + embedding-ভিত্তিক সেমান্টিক সার্চ
